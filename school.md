This page collects my school work and projects. To add a project, create a Markdown file in `_projects/` with front matter like this:

```yaml
---
layout: project
title: Project name
date: 2026-01-01
caption: A short summary shown on the project card.
description: A fuller description of the project.
---
```

Then add the project details below the front matter. You can also add an `image` and `links` to the front matter.
